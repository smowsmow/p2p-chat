新增聯絡人

和朋友直接互傳訊息與大型檔案，沒有一般通訊軟體的檔案大小限制。只需配對一次，之後雙方打開這個頁面就會自動連上。

邀請連結 遠端最方便

用 LINE、Email 傳給對方，對方點開就加入。需要把這個頁面放在網路上（例如 GitHub Pages），否則對方點不開，只能把連結貼到「我收到邀請」。

QR Code 當面最安全

面對面用手機掃描，不經過任何聊天軟體，旁人無法攔截。頁面放在網路上時，相機掃了會直接開啟。

邀請碼 到處都能用

一小段文字，對方貼到「我收到邀請」即可。頁面只是本機檔案時也能用，是最穩定的選擇。

這三種方式內容相同，對方任選一種加入即可。每個邀請只能使用一次，1 小時後失效；對方加入時，你這邊需要開著這個頁面。

目前是從本機檔案開啟的，對方點連結會打不開。請對方把整串連結貼到「我收到邀請」，或改用邀請碼。想讓連結能直接點開，可把這個檔案放到 GitHub Pages 等網站。

邀請碼

對方在「我收到邀請」貼上即可加入。

貼上收到的邀請

邀請連結或邀請碼都可以，直接整段貼上。

進階：手動模式（完全不經過中繼，雙方各交換一次連線碼）

適合在沒有網路中繼的環境（例如同一個區網、無法連外）。需要把邀請碼和回應碼來回傳一次，可另外設密碼保護。

A 方：發起

① 產生後傳給對方　③ 貼上對方回傳的回應碼

B 方：加入

② 貼上邀請碼，產生回應碼傳回去

所有訊息與檔案都直接在兩台裝置間傳送，並經過端對端加密：每次連線以 ECDH 結合抗量子的 ML-KEM-768 產生新金鑰，內容用 AES-256-GCM 逐塊加密驗證並定期輪替金鑰，雙方以裝置身分金鑰簽章防止冒充。公共中繼只轉交加密過的連線資訊，看不到內容，也不需要帳號。訊息與檔案不會被儲存。
