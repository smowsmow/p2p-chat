# P2P 加密通訊

讓你和朋友**直接互傳大型檔案與訊息**的點對點（P2P）小工具。不需要註冊帳號，也不需要安裝。

Discord、LINE 等通訊軟體對檔案大小都有限制，這個工具則讓檔案直接從你的裝置傳到朋友的裝置，不經過任何雲端空間，也沒有人為的大小限制，內容全程端對端加密。

**立即使用：** https://smowsmow.github.io/p2p-chat/

整個程式只有一個 `index.html` 檔案，也可以下載到電腦上用瀏覽器直接打開。

---

## 功能

- **免帳號**：第一次打開時，瀏覽器會自動產生一把專屬的身分金鑰，它就是你的帳號。
- **點對點傳輸**：訊息和檔案直接在兩台裝置之間傳送，不經過任何伺服器，也不會被儲存。
- **端對端加密（抗量子）**：每次連線都會產生新的金鑰，並結合抗量子演算法；訊息與檔案逐塊加密、驗證完整性，傳輸中自動輪替金鑰。加密不會拖慢傳輸速度。
- **傳送大型檔案**：可以用按鈕選擇，也可以拖放或貼上，一次可傳多個檔案，有進度條，圖片會直接預覽。程式本身不限制檔案大小，實際上限取決於雙方裝置的記憶體與網路速度，一般建議單一檔案在數 GB 以內。傳送期間雙方都要開著頁面。
- **表情符號**：內建常用表情面板。只傳表情時會放大顯示。
- **聯絡人與自動重連**：只需要配對一次，之後雙方打開頁面就會自動連上。
- **安全碼驗證**：可以和對方比對一組數字，確認沒有被冒充。
- 支援深色模式和手機版畫面。

## 如何加好友（三種邀請方式）

按「新增聯絡人 → 建立邀請」，會同時產生以下三種邀請，內容完全相同，對方任選一種即可：

| 方式 | 適合情境 | 說明 |
|---|---|---|
| 🔗 邀請連結 | 遠端，用 LINE、Email 傳 | 對方點開連結就會進入加入畫面，按一下即可 |
| ▦ QR Code | 面對面 | 對方用手機相機掃描，不經過任何聊天軟體，最安全 |
| 🔑 邀請碼 | 任何情況 | 一小段文字，對方貼到「我收到邀請」即可 |

注意事項：

- 每個邀請**只能使用一次**，**1 小時後失效**。
- 對方加入時，建立邀請的人需要**開著這個頁面**。
- 配對完成後，建議按聊天畫面右上角的盾牌圖示，透過電話或當面和對方**比對安全碼**。數字相同，代表連線沒有被冒充。

### 手動模式（完全不經過中繼）

在沒有網路中繼可用的環境（例如只有區域網路），可以展開「進階：手動模式」，雙方各交換一次連線碼來連線，並可另外設定密碼保護連線碼。

## 安全設計

| 項目 | 做法 |
|---|---|
| 傳輸層 | WebRTC 內建的 DTLS 加密 |
| 金鑰交換（抗量子混合） | 每次連線同時使用 ECDH（P-256）與 ML-KEM-768（NIST FIPS 203 抗量子演算法），兩者結果一起推導金鑰。就算未來其中一種被破解（例如量子電腦），另一種仍能保護內容，可防範「先錄下、日後再解密」的攻擊 |
| 內容加密 | AES-256-GCM 逐塊加密並驗證完整性，任何竄改、重送或順序錯亂都會讓連線立即中止 |
| 金鑰輪替 | 每傳送 1024 個封包（約 16 MB）自動換一把新金鑰，舊金鑰立即清除。就算某一刻的金鑰外洩，也無法解開之前的內容 |
| 長度隱藏 | 文字訊息補齊到 256 位元組的倍數，旁人無法從封包大小推測訊息長短 |
| 身分驗證 | 每台裝置一把 ECDSA（P-256）身分金鑰。握手時雙方簽署整段握手內容，並綁定這條連線，可防止中間人攻擊 |
| 金鑰保存 | 私鑰設為不可匯出，只存在你的瀏覽器裡（IndexedDB） |
| 邀請 | 一次性、1 小時過期。邀請內含隨機密鑰和邀請者身分指紋，只有建立邀請的那台裝置能回應 |
| 訊息紀錄 | 不儲存，關掉頁面就消失 |

### 公共中繼的角色

兩台裝置在建立直連之前，需要先交換一次「怎麼連到我」的資訊。這個程式借用公共的 MQTT 服務（EMQX、HiveMQ、Mosquitto）來轉交這份資訊：

- 轉交的內容已經用你們配對時共用的密鑰加密，中繼看不到內容，也無法冒充。
- 中繼只參與「找到對方」這一步。真正的訊息和檔案都是點對點直接傳送。
- 中繼可以看到連線的 IP 位址和時間。如果介意，可以在設定裡關閉中繼，只用手動模式。

另外，為了讓不同網路之間能夠直連，程式預設使用公共 STUN 服務（Google、Cloudflare）查詢自己的公網位址，也可以在設定中關閉。

## 隱私：這個程式存了什麼

**開發者沒有經營任何伺服器，也不收集任何資料。**

程式只在**你自己的瀏覽器裡**（IndexedDB）保存以下資料：

| 資料 | 用途 |
|---|---|
| 裝置身分金鑰 | 代表你的身分，私鑰無法匯出 |
| 聯絡人清單 | 對方的 ID、公鑰、名稱，以及自動重連用的配對密鑰 |
| 設定 | 暱稱、是否使用中繼和 STUN、是否已同意使用條款 |
| 尚未使用的邀請 | 讓你重新整理頁面後，邀請仍然有效（最長 1 小時） |

- 訊息與檔案**不會被儲存**，關閉頁面就會消失。你下載的檔案只存在你自己的裝置上。
- 你可以隨時在「設定 → 清除本機資料」刪除以上所有資料。開發者無法替你刪除或找回任何資料。

### 第三方服務看得到什麼

| 服務 | 看得到 | 看不到 |
|---|---|---|
| 網站主機（GitHub Pages） | 依其政策可能記錄造訪者的 IP 等存取紀錄 | 你的身分、聯絡人、訊息、檔案 |
| 公共中繼（EMQX、HiveMQ、Mosquitto） | IP 位址、連線時間、加密過的連線資訊 | 訊息與檔案內容 |
| STUN（Google、Cloudflare） | IP 位址 | 其他任何內容 |
| 與你連線的對方 | 你的 IP 位址（點對點連線的特性） | — |

請只和你信任的人連線。

## 限制

- **雙方都要開著頁面**才能收到訊息。關掉頁面、或手機瀏覽器長時間在背景時就收不到，也沒有離線訊息。
- 部分嚴格的網路環境（例如某些公司網路、雙方都在嚴格 NAT 後面）可能無法直連。
- 身分和聯絡人存在瀏覽器裡。換瀏覽器、換裝置、清除網站資料後，都需要重新配對。
- 在 Firefox 中直接打開本機檔案時，可能無法保存聯絡人，建議改用網址開啟，或使用 Chrome、Edge。
- 這是個人專案，未經第三方安全稽核，請勿用於需要高度安全保障的情境。

## 支援的瀏覽器

最新版的 Chrome、Edge、Firefox、Safari（包含手機版）。

## 本機使用

下載 `index.html`，用瀏覽器直接打開即可，所有功能都能使用。但邀請連結只有在頁面放在網路上（例如本站）時，對方才能直接點開；從本機檔案打開時，請改用邀請碼或 QR Code。
